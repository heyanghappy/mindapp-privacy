# mindapp-privacy

极简冥想（MindApp）的隐私政策站点，通过 GitHub Pages 发布。

- 线上地址：https://heyanghappy.github.io/mindapp-privacy/
- 对应 App：极简冥想（Android `com.astramind.mindapp.app` / iOS `com.astramind.mindapp`）
- 运营者：北京尚灵科技有限公司

## 更新流程
1. 编辑 `index.html`（保持中文、移动端友好）。
2. 提交并推送到 `main` 分支。
3. GitHub Pages 会自动重新发布，通常 1–2 分钟生效。

## 注意
- 该 URL 需在 App Store Connect、Google Play、vivo 等各应用市场的「隐私政策网址」处填写。
- 应用更名 / 改包名 / 新增 SDK（如友盟、内购）后，记得同步更新 `index.html` 的「应用信息」与对应章节。
